# 手动文献库与来源分区

种子入口为 `/Users/xiaoyanhao/data/文献库`。现有材料后台按配置间隔扫描，按字节指纹与 DOI 关联已登记原文，登记手选种子及优先级。PDF 原位保留。双击 `文献库索引.html` 可浏览“已有成品卡”“可预览候选卡”“暂无可展示卡片”，并打开原文和当前卡片文件。结构完整且与目录内原文同源的当前网页卡可以先展示候选摘要和核验状态。身份、版本、范围或人工决定受保护的候选卡不展示。核验和修正继续走现有后台流程。成品判定要求同一原文指纹、当前卡片版本的通过记录、科学核验及生产合同标记。

桌面“文献暂存”只放手动拉取 DOI 的普通原文。确认身份后导入为普通候选（`candidate=True`），不设种子、不写 `manual_card_priority`，与自动拉取文献同等进入普通精选/制卡排序；PDF 移入 SSD `library/manual`，桌面入口保留。补充材料不能单独作为原文，保留在入口并标记待核对。Word 阅读笔记只关联唯一已登记论文，不把笔记正文送入模型，也不单独移动。

精读库有“普通”和“手动”两页。“手动”下有“种子文献”和“衍生文献”：前者只来自 `library/seeds`/文献库种子，后者来自这些种子的检索来源链。`文献暂存` 的普通原文不进入“手动种子”分区；它按普通候选参与精选。多来源与原始根种子独立持久保存；旧记录只有唯一完整标题证据时回填。

分区继续按当前完整修正及科学核验通过条件展示，按真实分数排序，支持原有搜索、已读和撤回。未验收的种子在种子/任务记录中保留，但不会提前显示为已验收卡片。

`manual_literature.seed_directory` 指向原位种子入口，`keep_seed_originals` 启用保留及索引，`scan_interval_seconds` 设置刷新间隔。原位登记仍是持久手选种子，移出后只从本地索引消失。扫描回执写入 `infrastructure/data/manual-literature-status.json`，单文件错误单独记录。

内部列表接口新增 `tab=deep_regular|deep_manual_seeds|deep_manual_derived`；分页、搜索、已读与核验约束和原 `deep` 相同，`deep`仍返回全部合格精读卡片。响应stats包含三个分区数量。此接口不启动任务、不改变模型输入。

实现及验证：[授权](/Users/xiaoyanhao/project/paper/infrastructure/docs/authorizations/20261012-manual-literature-library.md)。离线测试覆盖去重、原文版本保护、笔记隔离、未知回执保护、种子递归与循环、多个来源、分区排序/分页和读状态。隔离浏览器验证按钮切换、搜索、已读撤回；不连接生产CDP或发送模型请求。

生产核对：当前暂存两项均关联已有原文/卡片，登记2个手动根种子、647篇具有明确来源证据的衍生文献。合格普通精读卡片13篇，手动两子页均0篇（仍等待完整验收，不放宽条件）。来源图回填由逐节点SQL改为一次载入、内存遍历和批量落盘，实测同一来源链耗时由22.67秒降至0.076秒，避免扫描长期占用写锁。184项相关回归及两个隔离浏览器用例通过；优化后35项来源/入库回归通过。
