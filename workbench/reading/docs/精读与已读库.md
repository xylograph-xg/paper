# 精读与已读库

## 当前可用功能

工作台文献列表先对全部符合条件的文献排序，再分页显示100篇（获取待办保留获取顺序）：总分 = 文献总体质量分（`paper_evaluation.overall_quality.score`，0–100）＋当前版本独立核验分（`card_review_jobs.result.weighted_score`，0–100），满分200，从高到低。总分同分时依次参考文献总体质量、方向新颖性、入库时间和ID稳定排序。精读与已读库使用同一规则，列表同时显示总分、总体质量、核验分和方向新颖性。

缺少任一真实分数时，总分显示“待完整评分”并置于完整评分之后；缺核验分显示“待评分”，不会补零或默认分。未完成核验报告中已有的真实评分可以参与排序，但明确显示检查未完成/需处理/退回重做；总分不代表科学验收。文献评分仍要求理由和合法原文页码，不以核验分替代文献分。核验分须对应当前卡片SHA-256及原文登记哈希，卡片或原文更换后旧版报告不混入排名；仅通过后新增元数据的已核对发布别名沿用同一报告。用户授权见[总分排名授权](/Users/xiaoyanhao/project/paper/infrastructure/docs/authorizations/20261009-combined-score-ranking.md)。

点击“标记已读”从精读库和待筛选隐藏，在“已读库”中保留，可点击“设为未读”撤回。已读库沿用评分排序；种子库和“全部”仍可找到该文献。标记已读是阅读进度，不是人工科学决定、生成验收或删除文件。

“添加备注/编辑备注”提供最多20000字的纯文本记录，可展开查看，也可在搜索框检索。备注不会被解释为HTML或进入科学卡片与模型材料。备注与已读状态跨刷新、后台服务重启和远程电脑持久保留；所有连接使用同一阅读记录，并不是各电脑各自的已读库。

两台电脑同时编辑同一备注时，旧版本保存返回冲突，保留当前编辑框里的草稿，不覆盖另一台已保存的内容；先复制需要保留的草稿，再重新打开核对最新备注。网络回执不确定时提示核对，不自动重复提交。

本次13项隔离浏览器脚本通过，含1280/720窗口与390像素标签行、图文2:1、独立滚动、数学/科学字符保护、LAN安全渲染、登录/CSP、备注冲突和不确定操作回执不重发。使用合成文献、临时数据库或拦截页面，不操作生产制卡页，不外发真实模型材料。最后的数学边界局部修复重新验证阅读器布局，其余脚本在该局部改动前已通过。正式工作台逐次读取HTML，无需重启；只读实机核对新版模板一致，原工作台服务保持运行（端口 8767；旧记录中的 20428 是当时进程号，不是监听端口），刷新网页即加载新布局。[不可变验收记录](/Users/xiaoyanhao/project/paper/infrastructure/data/audit_index/workbench-reading-layout-20261009.json)。

`GET /api/reading?id=<paper_id>`读取一篇文献的`is_read/read_at/note/note_version/updated`；`POST /api/reading`提交`id`与布尔`is_read`，或文本`note`与当前整数`note_version`。两项也可一次提交，但备注冲突会回滚整个请求。默认未读、空备注和版本0；相同已读状态不改变时间，相同备注不递增版本。修改仅使用工作台现有访问口令与来源限制；400表示输入错误或文献不存在（实现以KeyError回400），404只用于未命中路由，409表示备注版本冲突。

阅读状态保存在主Catalog的独立`paper_reading_state`表，不改`papers.decision`、种子、任务队列或卡片文件。事件`human_reading_update`仅记录改变的字段与备注版本，不存备注正文。`Catalog.get/list`不携带私人备注，供原有生成流程继续使用；阅读状态只通过工作台分页与阅读接口暴露。数据库沿用原有独立备份策略，不将个人备注纳入Git快照。

`paper_card_scores`是现有卡片的可重建索引。列表通过当前卡片/原文指纹连接独立核验表，提供`review_score`、`total_score`、`review_state`和`review_full_source_checked`；尚未建核验表时返回空分而不启动任务。保存卡片哈希、原文登记哈希及文件属性，发现卡片文件或登记来源改变后重新解析。读取JSON在写事务外完成，入索引前核对Catalog仍指向同一材料；没有修改卡片、补写分数或重新提交请求。新增阅读、分数索引及核验记录修改会更新Catalog版本，让远程页面刷新缓存。常规读请求保留有限重试，阅读修改不自动重试。

## 自动分区建议（等待用户确认，尚未启用）

采用固定主题目录、多标签与动态检索，保持文献及附件的一份记录，同一文献可以出现在多个分区。类似Zotero的集合与标签：[官方说明](https://www.zotero.org/support/collections_and_tags)。

按当前研究主题，建议先设六个一级分区：

1. OLED / TADF与器件性能
2. 激子动力学与能量转移
3. 单线态裂分与三线态对
4. 自旋与量子相干
5. 分子与材料设计
6. 表征方法与理论计算

另设“待分类”，作为证据不足或主题不明确的入口。方法标签（如瞬态吸收、EPR、计算）和材料标签（如rubrene）供交叉检索；不把每个新关键词都建成文件夹。高分已读、最近阅读、有备注等使用动态筛选，避免重复人工归档。

第一版建议使用本地规则：从题名、摘要和已有卡片提取中英文主题关键词，以受控词表和组合条件匹配；匹配明确时自动归入相应分区，展示命中的文本与来源，冲突或不足时留待分类。个人备注不用于自动归类、不上传；不启动新的模型或补做科学分析。分类是导航标签，不宣称科学核验。

标记已读时分类，已读历史可一次补分类；卡片或元数据更新后，仅更新没有人工锁定的分类。用户手动添加/移除的归属优先，自动规则不能改回。采用独立的分区、文献归属和规则版本记录，不移动PDF或卡片目录。

待确认：这六类是否适合，以及是否接受“一篇多区”。确认后再实现分区树、标签筛选、分类说明与人工调整；当前已读库仍是单一列表。
