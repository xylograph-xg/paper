本轮修改 `workbench/reading/reading_bridge.py`，新增 `workbench/reading/source_media.py` 与 `workbench/reading/media_evidence.py`，工作台新增证据入口。公共 read 解析器/分析器/导出器保持权威实现，通过精读子进程内的可恢复调用钩子适配；不复制公共实现。

## 图片

- 有可核验 arXiv 版本时，按该版本的官方 `/src/<id>v<n>` 地址获取源码包。以正在阅读的 PDF 首页版本标记为准；期刊 PDF 不自动与预印本源码混配。
- 原始压缩包、解压文件均保留。静态解析 `figure` / `figure*` 的 `includegraphics`、`caption`、`label`、`graphicspath` 和主文 `input` / `include` 文件树。记录出处文件、行号、宏及未解析路径。
- 源码原图文件不替代 PDF 组合截图。PNG/JPG 直接预览，JPEG 与 PDF 原图生成 PNG 预览；PDF 原图预览只展示首页，完整原文件仍保留。EPS/PS 等保留原文件，不执行转换脚本。
- 卡片图注与主文源码图注达到高相似度、且匹配唯一时才关联；不同图的顺序不能作为匹配证据。未确认的原图独立列入源码索引。
- PDF 截图由页面组合渲染，保留矢量、子图、坐标与图例。对底部图注的布局，按邻近图形/嵌入图像边界扩展疑似截断的顶部，止于前文/其他图注；保留原置信度，不能保证任意出版格式裁切正确。每张图额外保存整页截图供核对。
- 同字号双栏图注尝试拼接延续部分，附近正常正文不拼入。该规则已在原问题论文上检查，复杂跨页布局仍需核对。

## 公式

- 截图作为原式展示；同页多组使用 `Media_eq_001` 等唯一目录，避免覆盖。解析器的组内成员不再重复生成卡片，同名组标签补唯一候选标记。
- arXiv 源码保留 equation、align、gather、multline、displaymath、eqnarray 及星号环境、独立 `\[...\]`；保留自定义宏原文和 .sty/.cls 宏定义，完整源码包可补查依赖。静态解析不执行 TeX，因此动态宏、条件分支、某些自定义环境可能遗漏。
- 源码公式独立保留为可检索文本，**未自动确认其与某张 PDF 公式截图一一对应**；不猜测对应关系，不宣称独立渲染通过。
- PDF 公式的视觉转写复用既有 gemma4:31b / Ollama 客户端，在原串行阅读任务中执行；文献工作台不再初始化可选 pix2tex 小模型。输出做 JSON 格式、花括号和环境配对、非公式命令检查。
- 上述检查只说明基本语法，不能验证上下标、矩阵元素、分段条件或多行推导的科学正确性。输出始终标记未人工核验；失败或不确定时保留截图，不补造 LaTeX。
- 没有可靠检测框时不声称完成公式 OCR；保留原 PDF，已检测图/公式保存所在整页。扫描件与复杂版式定位仍属限制。

## 存储与调用

仅选为精读的文献在 Studio 精读目录生成这些证据，普通 PDF 仍按现有 SSD 策略归档。原有卡片文件和人工核对标记保留。

- `arxiv_source/<version>/source.archive`：源码原始包。
- `arxiv_source/<version>/files/`：原图、TeX、样式及其他提交文件。
- `arxiv_source/<version>/index.json`：图注/标签/公式/宏静态索引。
- `source-status.json`：源码请求的版本、来源、归档哈希、错误与退避时刻。
- `Fig_*/figure.png`：PDF 组合截图；`Eq_<首个编号>/equation.png` 或 `Eq_p<页码>_<区域身份>/equation.png`：独立公式组截图；渲染和导出使用同一路径，旧 `Media_eq_*` 产物不自动删除。
- `Media_page_*/page.png`：整页核对截图；`Media_original_*/preview.png`：源码原图预览。
- `media-evidence.json` 与 `card.meta.media_evidence`：哈希、出处、匹配状态、转写状态及完整源码索引。

下载上限 20MB，展开上限 100MB/2000 项，拒绝绝对路径、路径穿越、重复路径、链接和特殊文件；不编译或执行下载的 TeX。源码失败不替代 PDF，不终止后续模型阅读；失败 24h 内不重复请求，之后再次运行该文精读时可以重试。沿用既有 arXiv 持久化节流。页面对源码文本转义，宏只作为文本保存，不自动执行。

桥接协议依旧接受 `{out_dir, model, force?}`，模型输入不加入无匹配源码的推断。已核对且 PDF 哈希相同的卡片可仅补证据，不重写内容。`force=true` 允许重建；普通已完成机器卡再次运行会重建，失败机器卡仅重试失败部分。

## 验证与限制

67 项离线测试通过。样例源码验证了嵌套图注、输入文件树、图片路径、自定义宏、多行公式；路径逃逸/符号链接拒绝；同页公式截图独立。浏览器样例验证 PDF 整页、原图预览、LaTeX/宏以及恶意源码文本转义；实际论文主卡仍为 8 图、6 处公式渲染、0 个 KaTeX 错误。

实际网络检验 arXiv:2607.08634v1：`/e-print/` 和论文页指定的 `/src/` 都返回 HTTP 406，源码获取未成功，不能把样例解析验收写成实际下载验收。其现有卡片已补入获取状态和整页证据，未改写原结论。原问题论文为期刊 PDF，没有可确认的 arXiv 首页版本，保留 PDF 证据，不强配预印本源码。实际大模型公式转写本轮未单独运行，以免与正在进行的串行阅读任务争用；已完成调用适配与模拟客户端测试，真实正确率待后续公式样本核验。
