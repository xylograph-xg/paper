# 网页卡片高清图像展示

2026-10-07：网页卡片原先每项关联220dpi整页PNG，展示时被压至650px高，小字随整页缩小。改为独立展示派生层，科学card.json、已发prompt/packet/回答与评审指纹保持原样。

- pipeline/card_display.py复用现有本地PDF解析及通用图形边界扩展。只对原文同页、编号唯一、明确图注且存在图形的Figure，或明确编号且唯一的公式组生成300dpi裁图。子图标签、多编号歧义、跨页图注、不确定定位及表格保持原页查看，不猜裁剪坐标。几何扩展不等于人工核验，裁图明确标自动定位待核对。
- 派生图像和display/index.json放在SSD原卡片目录；index绑定card/source SHA256与版本。工作台核对原始card.json哈希、数组索引、标签、页码后才展示裁图，不把别张卡片的裁图套用过来。
- 点击裁图或“放大查看”进入独立大图视窗，支持适合宽度、100%、150%、200%与滚动查看，解除原650px上限。每项可直接打开对应页PDF；PDF原有矢量内容可继续放大，嵌入位图仍受源文件清晰度限制。
- 原220dpi整页与上传visual.pdf输入策略不变，不重新外发。保留原页及科学摘要核对入口。
- 现有web-tab-watch每10分钟本地维护补充新卡片的展示图，不重启生成worker、不增加模型或网页请求。输入未变且版本相同复用缓存；解析失败/超时记录该输入失败并使用整页，不确定性同输入不循环。更新只清理display内过期派生PNG，不删原页/卡片/评审材料。

验证：6项单元回归；独立临时工作台的浏览器回归验证裁图显示、100%/200%原尺寸、对应PDF页、关闭大图保留卡片及无JS错误。已有SSD裁图做人工抽看，仅验证抽样图像展示，未宣称全部科学图式或裁图边界通过人工验收。实际覆盖与缓存指纹见data/interface_changes/card-display-20261007.json。

公共web_gpt接口、模型提示和科学生成契约未改。此次只修改paper本地显示派生层、HTML与现有维护消费端。
