# 当前工作流与维护边界

## 当前入口

任务面板按config/task_panel_projects.json读取各项目，只提供主目录拉取与GPT制卡分别启动/停止；退出面板不停止常驻服务。启动文献工作台.command显示真实card_path的卡片；article/open_gpt.command是用户主动开页入口。后台不创建窗口或页面。

主目录拉取恢复，约30%元数据精选生成；限定10篇GPT重做优先且保护人工卡。GPT是当前唯一提交通道；所有本地模型和历史循环保留暂停。完整授权见[AGENTS.md](/Users/xiaoyanhao/project/paper/AGENTS.md)。

## 职责

| 层 | 实现 | 责任 |
| --- | --- | --- |
| 当前规则 | AGENTS.md | 授权范围与长期保护；旧授权归档 |
| 控制 | pipeline/control.py、config/control.schema.json | 严格读取、暂停/验证/额度优先级、串行写入与变更历史 |
| 编排 | web_card_pool、web_card_queue、web_card_service | 任务转换、原会话对账、结果发布；未知提交不可重发 |
| 通道 | web_card_transport及共享web_gpt | 真实设置/附件/DOM提交/完整收取，报告可失败状态 |
| 证据 | web_card_evidence、packet/attempt/raw/provenance及data/audit_index | 冻结输入、原页引文核对、原始回答与内容哈希；保留实际上传视觉PDF |
| 用户操作 | pipeline/action_inbox.py | 登录/验证/开页/归属核对；额度冷却由机器等待 |
| 状态视图 | continuous_status及共享任务面板 | 进程运行与实际任务推进分开，真实阶段与上海时间 |

统一决策输出scope/state/reason/source/expires_at/requires_user_action/allowed。暂停优先；记录损坏阻断执行；通道关闭不自动恢复；明确网站额度时间必须绑定原提示，冷却探测不宣称网站刷新。

控制文件按生命周期保留独立，避免不同写入者覆盖；写入统一锁且保留control-events.jsonl。这是本地变更历史，需要与数据库一起备份，不能仅依赖Git。旧状态快照不直接覆盖运行控制。

结构完整的card.json仍为科学未核验、生产合同未适配（not_adapted）。原页引文匹配状态由独立evidence字段记录，不冒充科学核验或本地模型合同完成；工程测试不代表科学评分通过。当前没有自动复评循环。

## 管理与验证

- 只读常驻状态：python -m pipeline.resident status --config config/first_round.json。
- 用户主动启动/停止：python -m pipeline.continuous_start --target fetch/cards；停止加--stop。cards启动加--open-browser仅用于用户主动开一个GPT主页。
- 只读用户操作：python -m pipeline.action_inbox；落盘收件箱使用--write，页数检查也会刷新。
- 全量隔离回归：make test；依赖见requirements-test.txt。测试仅使用合成材料/临时数据库和本机临时HTTP端口，不运行真实模型/出版商/网页提交。
- 主配置`local_models_enabled=false`，即使运行暂停文件缺失也不能启动本地模型。CLI保留兼容入口；本地配置只在实际模型执行边界验证，主拉取/网页服务不依赖Ollama配置。恢复需用户明确授权，并同时变更功能开关与对应暂停状态；本次不迁移科学生成代码或恢复旧入口。
