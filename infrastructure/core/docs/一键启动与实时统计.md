# 一键启动与实时统计

工作台按钮“一键启动拉取和GPT制卡”，以及项目根目录同名 `.command`，只恢复主目录文献拉取和GPT网页版制卡。桌面任务面板自动列出该命令。启动复用既有LaunchAgent，无强制重启；不恢复本地模型和历史隔离任务。浏览器只在用户主动点击此入口时沿用现有GPT打开脚本，后台仍不自动创建页面。

当前只允许ChatGPT通道，Qwen/DeepSeek不自动接管。已提交或归属不确定的请求继续原会话核对，不重复发送。

网页工作台和桌面任务面板共用主Catalog统计：总入库包含仅元数据书目；原文已下载按 acquisition=available；已制卡按主目录 card_path 记录，未宣称独立科学验收通过。上次完成时间取 web_card_generated 事件并转换为上海时间。队列显示排队、待核对和当前生成数。服务进程、浏览器等待与SSD等待分开显示。

“无可立即下载候选”会说明检索返回数量、过滤后新增下载任务数、退避候选数及下次重试时间。它不等于拉取服务停止；源站限流/禁止访问后的退避与已有失败保护仍生效。

验证：26项本地启动范围、权限和面板测试通过；无头浏览器验证数量显示、一键POST与刷新通过。测试不会启动真实模型或上传材料。
