# 异常自动处理

用户不需要逐条处理技术故障。原材料线程每60秒安排本地核对，维护原异常记录并保存automatic-issue-status.json；原网页所有者继续每10秒观察、每30秒故障核对及每60秒有限重试。准备与图像补齐可能超过一个周期，不重叠执行。

已授权重做的旧完整回答须核对原重做事件、旧卡/备份、归档意图、原报告及实际提示/原输入/回答指纹；只跳过对应已完成的旧回执。当前或不确定回执继续阻断。准备阶段确定未触及网页的失败可恢复材料等待并释放临时领取；恢复前后事务核对原队列、修正task指纹及暂停。

核验材料不足依既有规则有限补齐，有新增输入才复核；同证据失败只检查一次，原文歧义保留报告。后台不会生成未经原文确认的科学结论、清空旧回执、自动登录或处理验证码，也不自动解除暂停。额度仅按提示或冷却探测。

面板不再显示“后台处理与等待”及逐项技术操作。后台继续保留原异常、自动核对及处理结果；隐藏不代表问题解决。自动步骤由现有材料线程与唯一网页所有者执行，登录验证、科学歧义、未知提交及暂停边界继续生效。见[移除展示授权](/Users/xiaoyanhao/project/paper/docs/authorizations/20261010-background-issues-hidden.md)。

已进入needs_user但尚无核验报告的原核验请求，可在自动处理开启后由原所有者继续收取；仍要求原target、原review_id、唯一正式URL、实际提示、完整正文与冻结输入核对，不导航、不重发。已有科学报告的needs_user不走此收取路径。
