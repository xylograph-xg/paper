# 核验上传失败退避

2026-10-15，S002 工单（G-2/U-08）确认核验道同一 ZIP 每轮重新烧掉约 200 秒：`review_channel_recovery.recover` 把明确未发送的失败回执直接改回 `ready`，而 `card_review_jobs` 没有 `retry_at`，也没有任何技术失败计数。本轮授权见[核验上传失败退避授权](../../docs/authorizations/20261015-review-upload-backoff.md)。退避只调度**已经证明未发送的上传技术失败**；原文献、卡片内容、科学失败计数和历史回执一律不动。

## 什么才算一次上传失败

只有回执自身同时满足四条才计数：`state='not_sent'`、`send_click_started` 明确为 false、带有限 `finished` 时刻、带 `upload_failure_stage`。阶段由 `browser.web_card_transport.UploadStageFailure` 在点击发送之前抛出，分 entry（入口未就绪）、attach_write（原生文件写入失败）、attach_visible（附件未出现）、settle（结算超时）；旧回执 attach 继续可读。用户暂停、附件额度、访问验证、冻结材料变化、`Locator`／提交锁超时和任何未知回执都不计入，它们继续由原通道门与不重发规则处理。

计数发生在回执 `attempt.json` 已经持久保存之后，键为 lane＋job_id＋inputs_digest＋ZIP SHA，并另存由原回执 `created`／`finished` 派生的 `failure_receipt_id`。同一回执在双扫描、并发线程和所有者重启后都只计一次；`next_eligible` 只由回执的结束时刻加窗口推导，因此扫描或重启既不能补计失败，也不能延长冷却。成功发送只把连续计数清零，`total` 与回执证据永久保留。

窗口为 5 分钟、15 分钟，第三次及以后每 60 分钟低频自动重试（`card_review.upload_retry.backoff_seconds`）。这是技术退避，不是额度，也永不转成人工停止或丢弃材料。

## 冷却期间谁让步

- `shared_page_backlog._head`：冷却中的未领取核验材料与暂停队一样只是被跳过，后面的到期材料接着用这一页；not-ready、缺材料和归属变化仍然照原样挡住本页 FIFO，不当成冷却。
- `shared_workflow_queue.heads`：非混合入口用 `first_eligible` 在同一到达顺序上跳过冷却材料。
- 领取与最终发送：`ReviewLane.submit` 在 `BEGIN IMMEDIATE` 内先取到期行、再对**实际领取的这条**材料复核策略；提交锁内的 `before_send` 再核对一次，冷却到期本身不证明页面可复用。
- `recover`：归档/原租约核对仍走原链条，只有该链全部通过且不在冷却中才把作业改回 `ready`；未到期时保留回执原样，下一轮扫描再看。
- `reconcile`：冷却记录钉在原 target，计入 `physical_queued_tasks` 与 `upload_cooldown_tasks`，但不计入可派发库存，所以 85／100 补充与重组不会把冷却材料冒算成活动任务。已 `claimed`、实际上传中、未知归属一律不移动、不释放。
- 桌面 20×5 格：格位与标题保留，明细标注“上传失败退避中，稍后自动恢复原排名”，`runnable=false`。

优先级不变：用户暂停、账户额度、访问验证、人工决定、原文/版本/范围保护和真实在途生成始终高于到期；到期也不产生重发、关页或释放租约的权力。制卡额外 2 次与专项修复次数保持，本轮不新增任何制卡授权。

## 兜底与回退

策略行损坏（计数为负、非有限时刻等）或该材料冻结清单读不到时，调度侧把它标成非到期并写明待核对原因，领取与发送处显式拒绝——保留材料、停止该材料新领取，绝不当成零失败静默放行；其他材料与另外两队继续。核验冻结材料被真正重新准备后（新 inputs_digest／ZIP SHA）不再受旧记录约束，历史失败记录仍保留。

回退只需把 `card_review.upload_retry.enabled` 置 false：记录与恢复链退回原行为，`upload_retry_policy`／`upload_retry_receipts` 两张证据表继续保留，旧的无诊断码回执不批量回填、不解除未知状态，禁用也不会变成旧请求重发入口。表结构由 `shared_workflow_queue.install` 的原到达链创建，读路径从不建表。
