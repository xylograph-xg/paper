# 制卡文献评分标准授权（2026-10-09）

用户指出：“感觉整体质量的打分区分度不足，都被核验分主导了”。在给出实际分布和排序选项后，用户明确选择：“改变制卡时的打分标准，让他们更有区分度”。因此本轮调整生成时的文献评分标准，保持已授权的文献分加核验分排序。

总体质量采用通用分项依据、固定权重和明确高低档证据锚点，区别扎实常规、实质贡献与突出贡献。区分来自原文证据，不通过重写旧分数、强制分布、期刊偏好或核验分反推文献分实现。新颖性继续独立评价。

新版本随新准备材料生效；旧评分、已有卡片、人工决定、冻结输入和活动/未知请求保留，不自动升级或重新发送。允许本地解析、算术、索引与隔离显示验证，不启动额外外发重评分或历史循环。具体标准见[文献质量评分标准](../文献质量评分标准.md)。
