# 网页任务启动按钮自动运行浏览器启动代码

2026-10-10用户原文：“为什么我点了启动没有自动启动浏览器，我要求点启动就运行生成浏览器的代码”。

主目录制卡、核验、修正及原all入口每次显式启动都提交专用浏览器启动请求，不依赖旧open_browser开关。唯一常驻所有者执行启动代码：本机指定CDP已连接则复用，专用Chrome已有进程而端口未就绪则等待；无进程才后台open -gna启动指定profile/端口。启动意图先落盘，未知回执不重复开窗。独立入口不另连CDP、不重登记损坏窗口、不补开未知归属槽位、不外发未知材料。拉取入口不启动Chrome；仅恢复被点击任务，其他暂停、登录验证与额度保护保留。允许正常重载原所有者加载本次实现。

用户随后反馈停止再启动无反应，并明确“直接运行一个新开 chrome 窗口，然后打开 20 个 gpt 网页的代码不就行了”。本轮据此补齐唯一所有者的显式初始化：原登记窗口及所有旧target均消失时，新建带持久nonce的后台专窗，定向补足20页，保留旧登记及全部材料账本；新窗口/页面未知创建回执按nonce恢复，不重复创建。存活原专窗继续复用，不重复开20页；旧未知文献请求不重发。按钮回执仅称启动请求已提交，实际页面与任务就绪由实时状态确认。
