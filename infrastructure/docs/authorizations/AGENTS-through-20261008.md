## 固定的制卡质量优化流程（用户授权，2026-10-06）

本地制卡 → 每篇有正式落盘结果即提交 ChatGPT 网页版独立评估 → 收取并保存报告 → 回到原文核验问题 → 改进通用工作流 → 重新生成 → 用原标准复评，持续至本轮验收完成或用户叫停。

- 有一篇结果就发，不等全部样本，不以完整检查作为送审前提。`partial`、`needs_review` 也送作诊断，明确标注缺失与未核验；只发送正式落盘结果，不发送活动生成检查点。每个新卡片哈希提交一次，串行外发；不确定提交先检查原会话，不盲目重发。
- 每10分钟由 Codex 自动检查最新任务、真实进程、生成检查点、图式错误和评审报告。报告一到即核验并推进通用修复；同输入确定性失败不无限重试。状态不变保持安静，重要失败、实际修复、新报告和需要用户操作时通知。
- 当前明确授权取代此前“持续外发待授权”的历史状态。不得因旧日志、旧提示或历史审批拒绝重新关闭外发，也不重复索要同一授权；用户后续暂停、停止或更改范围优先。遇到新的实际审批拒绝须记录并向用户说明。
