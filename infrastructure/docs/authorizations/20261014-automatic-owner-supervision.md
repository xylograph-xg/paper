# 原所有者自动监督（2026-10-14）

用户原话：“为什么要手动，我的工作流是全自动化的”。沿用本聊天已批准的原服务维护及技术异常自动处理，补全现有 HTTP watcher 对原网页所有者的自动交接；不增加常驻入口或 CDP 所有者。

唯一监督入口是原 `local.paper.web-tab-watch`。它核对原 `local.paper.web-cards` 的注册、配置、PID、所有者令牌及暂停，在源码与全量测试、接口和全局链接验收指纹一致时才请求交接。双心跳均过期至少300秒且相隔至少60秒两次实查，或原所有者仍使用已被验收新版替代的源码时，可向该 PID 发送 SIGTERM，等待原进程退出，再 kickstart 同一个已注册入口。源码更新等待提交锁空闲；每小时最多两次、至少间隔五分钟。正常页面继续生成，原请求由新所有者按原账本收取，不重发。

验收记录仅表示确定源码已经测试，不允许监控执行任意未验收修改。退出或启动回执不明保持核对，不强杀、不并行启动第二所有者。原任务暂停、登录验证、额度、未知回执、人工决定及固定20槽保护继续有效。首次部署只维护原 HTTP watcher，使后续交接由它自动执行；不恢复其他暂停任务。
