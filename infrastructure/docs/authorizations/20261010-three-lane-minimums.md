# 三项网页任务最低并行授权

用户于2026-10-10明确要求：“把核验和修正的最低并行选项也打开”。

工作台和任务状态面板同时开放制卡、核验、修正的最低并行菜单，范围1–20，默认8、4、3。三项合计不能超过专窗20页。设置由控制写锁原子保存，只抬高不足的对应内部上限；降低最低值不降低已有上限。原所有者按健康页面库存调整预留，不抢占其他任务的在途、未知或受保护页面；不足如实记录。暂停和提交保护保持有效，实际并行仍只计实时核对的生成请求。
