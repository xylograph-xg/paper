# 手选文献候选卡预览（2026-11-10）

用户原文

> 我之前针对手选文献为什么没有成品卡的问题进行了多次维护，为什么还是没有成品卡，或者对核验降低要求，先展示，但是后续不断进行修复和核验？

原位文献库先展示当前同源、结构完整且未受保护的网页候选卡，单独标识状态并提供摘要和卡片文件链接。正式成品仍须当前卡片版本的科学核验和生产合同均通过。后台按现有规则持续处理可恢复的核验和修正，原文、卡片、报告、人工决定、暂停和未知回执保护继续生效。

## 文献工作台

用户随后要求“文献工作台展示，而且为什么在其他电脑上进入文献工作台需要密码”。工作台顶部“手选卡片”接入已登记手选根种子的同源成品与结构候选，候选卡在列表和正文显示当前核验状态。通过原鉴权后的工作台阅读器打开卡片。
