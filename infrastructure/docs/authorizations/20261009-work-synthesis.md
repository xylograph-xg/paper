# 工作总结层次与展示授权（2026-10-09）

用户先要求：“我还是需要一小段话总结工作，要求系统性总结”，并举材料性质、原理与性能提升的概括作为示意。用户随后明确澄清：“不是这么具体的，不同文章不要都套这种模板，只是意思是要上升到总结水平”。

生效要求是按文章自身研究逻辑写一小段全文层面的总结，提炼整体工作与核心贡献，不统一套材料—机制—性能等句式，不机械罗列具体材料或逐项结果。概括仍受原文证据、条件与推测语气约束。

现有 `one_line_summary` 用于工作总结，`key_findings` 保留具体结论与证据，两者在同一制卡回答生成。工作台列表与阅读器展示同一来源的总结，支持展开具体结论及检索；只建立派生索引，不改旧卡科学内容、人工决定或原报告。

本次只修改通用生成规则、新材料版本标识、派生索引与阅读展示；既有冻结材料和已发送/未知请求不因新要求改写或重发。本授权不恢复暂停通道、历史自动循环或新增外发测试。说明见[核心结论与卡片核验](../核心结论与卡片核验.md)。
