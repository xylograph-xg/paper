# 三次未通过退回重新制卡

用户明确：“所有阻塞的继续丢进循环，三次不好的打回重新制卡”。本授权取代核验/修正失败永久退出循环和每篇科学重做最多2次的旧规则。配置为 config/review-cycle-policy.json。

当前版本首次完整收取未通过后再独立核验两次；第三次完整收取仍未通过，原卡及报告保留，使用原文重新制卡，新卡独立核验。每次复核使用独立材料标识、回执和目录，旧报告不改判、不覆盖。修正失败同样转入独立核验循环，禁止重复应用失配字符串或越界科学修改。次数按当前卡片指纹与事件记录，技术发送前失败、额度等待和未知回执不伪装成已完成的科学失败。

未知回执、材料身份/版本/范围变化、人工保护仍由既有证据规则处理，在循环诊断中保留待处理原因，不重复发送或覆盖保护卡。用户暂停和网站额度限制实际派发，不代表任务永久退出。循环扫描复用原核验准备线程，不新增CDP连接或常驻入口。
