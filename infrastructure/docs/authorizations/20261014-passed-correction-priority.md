# 核验通过的修正持续置顶

2026-10-14，用户本聊天原文：“优先进行核验通过的修正任务，保持他们的置顶状态，阻塞怎么办”。

授权优先执行已有真实通过核验依据的修正，保持置顶并在既有边界内处理阻塞。配置 `card_correction.priority_passed_first=true`；完整原文检查、网页原报告判定通过、加权至少85、没有材料缺失和major/critical，以同原文指纹的不可变原修正输入为置顶来源。纯科学验收 `action=pass` 与带minor建议的 `model_report_pass=true/action=correct` 独立记录；置顶不修改科学通过统计。已绑定的后继原文重做及待核验新版继承优先；完成当前版本完整循环后不再作为待执行置顶任务。优先组内沿用真实文章分数、不可变入队时间和序号；已有活动、上传、发送、未知请求不抢占、不移动、不重发，固定20槽和8/4/3/5分组不变。

阻塞处理保留旧回执、报告、任务正文与原FIFO。已完整收取且证据明确的科学文字改写或无效排版位置，禁止本地改字，转已有原文独立重做与完整核验通道；新任务不上传旧科学答案。旧排版建议有原归属并已由核对过的正式新版或后续当前版本完整科学通过替代时，仅登记失效和后继证据，不伪造“修正已应用”。新版、身份、版本、原文、人工决定、暂停、额度和未知提交守卫继续有效。

没有真实修正建议的直接通过文章不捏造修正任务或完成链；精读库入库条件不改变。此条是本轮实现范围的记录，不授权强制修改科学结论、绕过额度或恢复暂停。
