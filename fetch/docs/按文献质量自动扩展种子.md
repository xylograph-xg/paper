# 按文献质量自动扩展种子

主目录fetch_pipeline.auto_seed_expansion=true。每次常驻检索在读取种子时重新检查持久暂停与当前队列：下载/兜底/导入无queued、running、waiting_storage，且没有已到期的pending候选，才从主库已完成GPT精选卡片中挑一篇总体质量分最高的未用种子。同分按固定ID排序；每轮最多一篇。原文有后续退避候选不阻止找新资源，不清除旧候选或失败保护。

候选须有有限0–100分、理由、原文页码、GPT来源及一致的原文指纹，且有可供关联搜索的DOI。信息不足/null不补造分数。已有种子、曾被人工移除/曾用种子、人工决定、拒绝/稍后、关联勘误、身份/版本/领域待核对等不参与。选中仅更新种子成员与来源证据，卡片内容和人工决定不改。记录seed_auto_quality事件、原卡哈希及评分依据。

新种子立即加入本轮参考文献/引用检索，下一轮正式种子列表也包含它。发现新书目沿用去重、领域过滤和有界PDF获取；不突破站点限流/下载失败保护，不恢复本地模型或历史隔离任务。自动入口只作用于主data目录；seed_related关闭或用户暂停时不扩展。

seed-expansion-status.json单文件保存实时触发状态，避免追加空轮次日志。2026-10-08实测状态waiting_scored_cards、符合条件评分为0，原7个种子保持不变；这是等待新卡实际评分，不代表服务停止或伪称已扩展。新评分正式落盘后无需再次点击启动即可参与。无法保证每一时刻都有可下载PDF。

验证：38项最高分排名、去重、队列触发、人工保护、用户暂停、退避不重置、原来源回退/分页与获取测试通过。
