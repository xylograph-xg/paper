# 持续拉取问题审查（2026-10-05 历史快照）

> 说明：本文是 2026-10-05 的一次性分析快照，所列 P1/P2 问题（单串行 worker、无持续监督、页码游标等）大多已由后续 `fetch` 独立服务、fast/slow/discover 三池和 `fetch-service.lock` 处理。保留本文用于追溯问题由来，当前实现与配置以 `fetch/README.md`、`infrastructure/config/first_round.json` 为准。

本次为分析，未改变当前 worker、目录资产、人工决定或卡片。核对源码、实际 SQLite 状态及日志，并使用临时数据库和模拟下载做针对性复现；34 项现有测试通过不代表不存在下面的问题。

检查时已获取候选 PDF 37 篇，修复后仍在新增；所有已记录资产路径存在。8 个模型阅读失败任务仍未恢复。

## 优先问题

1. P1：预印本版本可能错误标记。catalog.upsert 对 pdf_urls 的合并保留旧链接在前；acquisition 按顺序下载，remember_version 按最新 metadata 标记版本。临时数据库复现：v1→v2 更新后实际下载 v1 链接，却写 asset_preprint_version=v2。位置 pipeline/catalog.py 列表合并、pipeline/services.py acquisition。应使用版本明确的链接并核验返回版本；无法核验不能宣称最新版。
2. P1：PDF 身份判断过松。verify_identity 在目标 DOI 不存在时仅要求首页前两页包含题名 75% 的不同词，不要求这些词构成题名。临时模拟文本含不同 DOI 和通用词仍通过。无法区分正文 DOI 与参考文献 DOI时，不应简单拒绝所有不同 DOI；应识别标题区域、首页主 DOI并记录可信度，冲突转人工核验。未发现现有文件已经错配，此项是已复现的校验缺陷。
3. P1：单条异常仍可中断整轮。services.discover 的记录合并和 acquisition 没有逐项隔离；某条身份冲突、异常字段、PDF解析异常仍可使整轮失败。需逐项捕获、记录并继续，保留已经完成的入库统计。当前只修复了已知字符串/列表和空作者/链接两类错误。
4. P1：共享分页不能保证覆盖。页码在原始结果返回后立即前进，而一轮只尝试20篇、接收10篇，其余记录不进入持久待下载队列；之后直到50页轮转才再访问。三个来源共同前进，单来源失败也会跳过自己的当前页；空池会提前抛错，页码不前进。ChemRxiv rows=30、offset步长20有重复。需按来源/查询保存游标与待处理池，完成后推进，单来源独立重试。
5. P2：获取与阅读互相阻塞。一个串行worker同时执行检索、逐篇下载、模型筛选和精读；下一轮等待整个队列完成。长阅读期间没有新下载。应将获取与阅读拆为独立队列/worker，模型仍仅一个，PDF侧设置少量并发和队列上限，遵守来源限流。
6. P2：失败恢复不完整。8个引文校验失败无自动有限次重试。历史已有 candidate_order 且缺PDF的记录在 discover 中提前跳过，即使24小时过去也不会经由该路径自动重试。waiting_storage 会阻止继续调度，而挂载恢复后没有自动把这些任务排回队列。recover将中断任务标失败，需要人工重试。应按失败原因设置次数、下次时间和恢复条件，不能降低证据核验标准。
7. P2：异常运行不可见。工作台正常打开不代表worker仍存活，web服务没有持续监督/重启worker，进程退出后页面可能继续运行。无需Codex；可以在Python父进程中监督子进程、写心跳并在界面展示运行/退避/停止/错误。关闭终端和机器休眠仍会暂停。
8. P2：相关性污染与检索范围。实际已有 OLED-MoE 计算推理论文误入。新检索已排除特定缩写，但历史记录未重新检查，仅排除一个题名不能普遍解决缩写误匹配。期刊池也缺统一领域门槛。需主题上下文判定和历史复核，保留用户人工决定。

## 补充限制

- 快筛仅覆盖PDF文字层最多18000字符头尾，中间和图片未覆盖；核心结论不能等同于全文/图表验证，当前证据范围已有标注。
- Unpaywall邮箱未配置，尚未启用，获取覆盖不完整。
- 预印本与期刊版的 DOI 不同且来源缺少显式关联时，仍可能作为两篇记录保存；需显式关联，不能仅靠相似题名强制合并。
- 来源状态可能部分请求失败仍显示ok，应显示partial和每条查询进度。
- 34项现有测试通过；上面的两项临时复现说明测试尚未覆盖关键跨版本流程和弱题名错配，需要新增有针对性的回归验收。

建议顺序：先处理版本与身份校验、逐项故障隔离，再完善来源游标和持久待下载池；随后拆开下载与模型处理，加入失败恢复和Python进程心跳。
