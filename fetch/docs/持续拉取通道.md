# 持续拉取通道（fetch-v3）

2026-10-06：已实现独立于网页和本地模型的 Python 持续拉取服务。启用方式：

```bash
~/venv/bin/python -m pipeline fetch-start
~/venv/bin/python -m pipeline fetch-status
~/venv/bin/python -m pipeline fetch-stop
```

`fetch-start` 启动脱离终端的 Python keeper，再监督仅负责拉取的 worker；后台退出会退避重启，重复启动复用现有实例。`fetch-stop` 用身份令牌请求停止，不凭任意 PID 发信号。关掉网页或 Codex 不会停止此独立服务。系统关机后需重新执行启动命令。macOS 下 Python keeper 可管理 caffeinate 防止空闲休眠；断网、机器主动休眠和外置盘拔出时不能保证实际下载，队列保留并等待恢复。

## 调度与来源

- 检索仅发现和排队，当前配置为 8 个独立 Python 进程执行直链下载、4 个独立 Python 进程执行慢速 fetchpdf 后备（代码兜底默认值仍是 4/2，`concurrency_control.py` 会按总并发覆写）。MuPDF 解析不在线程间共享。没有直链的条目直接进入后备队列，不占快下载槽。
- 获取队列默认最多 200 个任务，慢回退队列默认最多 50 个任务（包括直链失败转入的任务）；低于低水位时独立补充检索。每次请求最多取 100 条元数据。模型筛选和制卡积压不会阻塞拉取，也不再按每轮 10 篇、20 次尝试限制吞吐。
- OpenAlex / Semantic Scholar 主题与种子关联检索；前两者失效时，主题检索使用 Crossref 书目后备。arXiv Atom API 与 ChemRxiv Crossref 前缀通道继续使用现有检索词。
- OpenAlex、Crossref 保存不透明游标；Crossref 不把游标和 published 排序混用，后续页携带相同过滤条件。arXiv 使用固定提交时间截止与 submittedDate 排序；来源结束时先保留结束位置，暂停后再扫描，避免每个不满页立刻回到起点。API 返回集合仍可能变化，按稳定身份去重，不声称远端结果是不可变快照。
- 成功页面立即写检查点。父进程中断可读回成功页；keeper 重启后恢复遗留检查点，记录与游标同一事务保存。单源失败不推进该源游标、不阻塞其他源。
- 429 的 Retry-After 保存在 `data/network-state.json`，到期后再请求；不在子进程里睡几小时。网络异常指数退避，快慢任务都有总时限。arXiv 元数据单连接且至少间隔 3.2 秒，PDF 保留 15 秒间隔；节流锁只用于预留时刻，不持锁睡眠。
- 初次激活新拉取政策时重新开放历史 pending 的重试窗口，旧错误和数据库基线保留；人工忽略、人工种子和卡片不覆盖。损坏/身份错误 PDF 不入库。没有拿到可核验 PDF 的条目不冒充已获取候选。
- arXiv 校验正文版本与可信版本 URL。正文明确是旧版时拒绝标新；强身份校验及明确 arXiv 版本 URL可确认目标版本。版本无法证明时保留可用 PDF 并标记待核对，不再整份拒绝、不假称新版。

普通 PDF 和原始书目响应存外置 SSD；统一编目使用 WAL 与批量读取，避免每遍扫描上千次数据库连接。人工上传仍由受控获取槽处理。筛选任务持续排队，但 fetch-only 服务不启动模型或网页评审。

配置在 `infrastructure/config/first_round.json` 的 `fetch_pipeline`、`pdf_retrieval` 和 `preprint_channels`。运行状态与日志为 `infrastructure/data/fetch-service.json`、`infrastructure/data/runtime.json`、`infrastructure/data/worker-fetch.json`、`infrastructure/data/logs/fetch-service.log` 和 `infrastructure/data/logs/fetch-supervisor.log`。

用户持久暂停记录保存在 Catalog 所在目录的 `fetch-control.json`。`paused_by_user=true` 时工作台打开不恢复后台拉取；`fetch-start`、keeper、fetch-only 监督以及直接 fetch/single worker 均遵守该暂停，状态返回 `paused_by_user`。未知/损坏的已有控制记录按暂停处理。仅在用户明确恢复后清除该标志；不得把手动打开查看页面当成恢复授权。控制文件按 Catalog 目录隔离，不影响两篇短文的独立读队列。
