# 核验本地准备的数据库锁恢复

核验材料线程在本地准备时遇到 SQLite `database is locked`，此前会把任务留在 `needs_user`，即使没有使用页面也不会再准备。异常自动处理现在检查这一种暂态故障，并恢复原核验任务的本地排队。

恢复要求任务仍为原状态、结果为空，正式卡片与原文指纹一致，且没有人工决定、身份/版本/范围问题或暂停。原准备目录及历史中不得有完整 packet、attempt、原回答、反馈或评估报告；不得有已领取页面材料或独立修正任务。所有条件在写事务内再次核对。

每个核验任务最多恢复两次本地准备，事件保留原错误、更新时间、原文/卡片指纹及次数。保留原入队时间、全局序号和部分材料；不释放页面、不外发、不增加或清零外部重试计数，不修改科学内容或评分。完整或未知回执继续只由原所有者核对。

恢复运行于既有材料线程的自动异常处理，无新连接、窗口或服务。测试覆盖暂停、人工保护、版本变化、历史回执、完整材料、已领取页面、已有修正、次数上限和重复调用。
