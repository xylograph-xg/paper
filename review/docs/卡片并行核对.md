# 主GPT卡片并行核对

主制卡后台同时维护独立科学核对队列，默认4路生成并行，本地材料准备和报告处理也并行。一个CDP连接、共享上传/发送锁、浏览器总20页上限；制卡数量和核对数量分别控制，容量不足时等待完成，不抢未知/活动/他人页面。工作台显示并行选择和暂停按钮，任务面板有独立“卡片核对”分组及并行菜单。

按卡片中有原文依据的文献总体质量降序，同分按方向新颖性排序，未知分数置后。这些是文献分数，不能当作核对评分。每个卡片SHA-256版本只入队一次；原文、卡片、附件和实际提示分别核对指纹。核验单ZIP包含净化原文、220dpi原文全页证据、完整文字层、卡片文本，以及实际卡片图像PDF；图像逐项页码映射、当前文件指纹和准备时指纹再次核对，不以原文PDF替代实际图像验收。大型PDF保存在配置的SSD核验目录，回执和指纹留本机。

## 小问题和大问题

- 逐字引文在已核对原文文字层中有唯一位置时，自动补充`evidence_source_page`，保留原`source_page`和图像。引文匹配只证明文字存在，科学核对继续。原卡片先保存到history。
- 模型建议只有空白/排版变化且字母、数字和数学符号完全不变时，可保存修正候选并发布；每篇一次，修正后重新核对。数字、单位、公式关系、上下标、共轭、版本、核心结论证据层级属于重大问题。
- 完整报告发现major/critical且有可逐字回查的原文证据时，备份原卡、原文和完整提交账本，归档后退回制卡队列，5分钟退避；完整核验连续三次未通过退回原文重新制卡（非循环分支仍保留最多2次上限）。新生成只有原文、空白结构和通用规则，没有旧卡片、旧评分或反馈答案。原卡片在新卡片发布前继续保留。
- 人工决定、身份/版本/范围疑点、报告读不全附件、来源歧义、不确定回执、指纹变化和重做上限转“需处理”，不直接修改科学内容。

## 通过标准和状态

每次核验独立评分：图像完整性25%、公式完整性25%、科学忠实度25%、可追溯性15%、阅读实用性10%；每项0–10，加权总分0–100。核验总分、分项、原报告、问题级别和处理结果分别保留。未核验显示“待评分”，读不全材料仍标“需处理”，不能因分数高就通过。文献质量分用于排队，核验分用于卡片质量，两者不互相替代。

独立科学核对要求原文身份和核心结论检查、全部原文页、全部图式表逐条检查，rubric加权至少85/100，verdict=pass，无问题及missing_inputs。通过状态绑定确切输入卡片指纹，完整回答、正式唯一URL和输入回执保存后才释放页面。生产合同仍单独标未完成，不写quality-ready。

“原会话待核对”是原制卡提交/收取异常；“卡片核对排队”是上述科学队列。两者分开显示，不清空旧异常来伪称核对完成。核对默认暂停随主制卡暂停，独立暂停也优先于并行调整和常驻重启。旧自动评审循环保持暂停。

实现：review/card_review_queue.py（版本队列、准备、判定、修正、归档重做）、review/card_review_lane.py（现有连接上的并行会话），由web_card_pool管理。配置card_review，持久并行concurrency-control.json的review字段，独立暂停card-review-control.json。

## 本轮实际验证（2026-10-09）

核验队列、分项权重、当前版本评分绑定、错误后保留评分、未知分置后、人工/暂停保护、图像指纹、原会话归属、有限归档重做及共享分配相关111项测试通过；新增当前持久并行设置测试后，45项核验与报告解析测试通过。共享窗口相关46项测试通过。隔离浏览器验证评分、分项、队列优先级、并行调整、暂停/恢复及无效设置不会部分修改暂停状态，无模型调用和页面脚本错误。

正式后台已经按持久设置核验10路、制卡6路运行，实际活跃数随待办和可用安全页面变化。多份GPT-6 High核验会话已经正式提交并收取；历史完整回答中的JSON代码块标题连写已在本地兼容解析，真实评分如42、44.5、52.5、83分已显示。首批报告缺少实际卡片图像，保留分数并明确未完成，未宣称科学通过。新版实际图像包已通过正式独立会话提交，结果仍分别记录，不以启动或提交当作科学验收。

后台更新交接曾使旧准备进程写入旧请求格式，修复后仅将239份无attempt、原文/卡片指纹一致且日志明确为该格式错误的本地准备任务重新排队；所有已发送会话保留，没有重发。远程工作台原端口和访问密钥、并行/暂停控制保持，浏览器未重启。验证留档位于data/audit_index的独立不可变索引；不包含原文/答案正文或访问密钥。
