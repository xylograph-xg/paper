# 核心结论与卡片核验

## 工作总结（2026-10-09）

用户要求保留“一小段话总结工作”，并澄清“不同文章不要都套这种模板，只是意思是要上升到总结水平”。因此 `one_line_summary` 沿用原字段名，生成含义改为全文层面的工作总结：按本文自己的研究逻辑提炼整体工作与核心贡献，呈现主要发现如何构成这一贡献，不逐个罗列样品、材料、数值或图式结果。没有统一句式，也不强制材料、性质、机制和性能等要素。

一小段约80–160字仅作篇幅参考。概括不能越过原文证据；必要条件和推测语气保留，不把特定对象泛化为整类材料规律、不把相关性写成确定因果、不补造机制或意义。总结与具体结论在同一制卡回答生成，结构非空检查不能判断提炼质量或科学正确性。授权原文见[工作总结授权](/Users/xiaoyanhao/project/paper/infrastructure/docs/authorizations/20261009-work-synthesis.md)。

列表和图式阅读器优先展示同一张卡片的工作总结，具体结论与证据放在可展开区域。列表搜索同时检索总结和具体结论。原卡没有总结时保留原具体结论并注明尚无工作总结；不从初筛或个人备注拼造总结。

规则版本为 `work-synthesis-v1`，随新准备材料的提示和包指纹记录，在新生成卡片元数据保留。此次不修改已有卡片、不升级既有冻结材料或重新发送在途请求；这些材料仍保留原规则，旧卡只展示原有总结。派生索引增加 `work_summary`，索引版本升至3，只在原文指纹一致时缓存原卡文字；旧缓存安全迁移，不改已读状态、备注或科学原文。

本轮26项总结、评分与索引测试通过；访问、后台服务和阅读保护36项中35项首次通过，慢连接压力项首次连接重置，隔离重跑通过。两项隔离浏览器回归验证总结首屏展示、详情展开、旧卡回退、检索、安全过滤、已读与备注以及并发草稿保护。真实API逐一核对271张卡，其中267张原文绑定有效的原有总结正确接入；重载前270张原卡全部哈希不变，期间有一张原后台新卡发布。原远程端口和访问口令保留。此轮没有新模型调用，不能据此宣称新总结质量或科学内容已验收。

## 核心结论的来源

核心结论使用 `card.json.key_findings`，与题名、研究动机、讨论、图、公式、表格在同一次制卡回答中生成。通用规则要求3–5条，每条保留研究对象、必要条件和原文页码/图式号，并区分直接观察、模型拟合或计算与作者解释。

解析器要求核心结论为非空字符串。缺失或空白不能通过卡片结构检查；这一检查不能证明结论内容科学正确。

工作台列表和图式阅读器共用此字段作为具体结论，总括段落另取上述 `one_line_summary`，列表搜索包含两者。旧 `assessment.core_findings` 是历史初筛结果，不作为制卡核心结论。已生成卡片但字段缺失、文件不可读或原文绑定未核实时，列表提示核心结论暂不可用；没有卡片时提示尚无制卡核心结论，不根据功能开关推断排队状态。

派生索引只缓存原卡片文字和指纹，不重新生成、不修改卡片或初筛记录。原文指纹改变、卡片文件改变或被移除时，索引重新核对或失效。旧索引安全增加字段并重新索引，不改变已读状态和个人备注。

## 初次接线时的检查状态（历史记录）

| 检查 | 实际检查内容 | 能证明什么 |
|---|---|---|
| 结构检查 | JSON可解析、必填文本非空、图式条目字段和页码映射、重复标签、评分数值范围及依据页码 | 输出满足当前基本字段要求；不能证明数值或解释正确 |
| 来源与材料核对 | 原文、输入、整页视觉材料及回答指纹，身份/版本/人工保护 | 材料归属和流程可追溯；不能证明读图或推导正确 |
| 引文匹配 | 图式引句在原PDF与发送文字层中逐字、同页出现 | 原句可以定位；不证明引用支持了卡片解释 |
| 独立科学复核 | 逐图逐式核坐标、单位、倍率、上下标、数值与条件、事实/模型/解释、核心结论证据链 | 当前没有运行此流程，历史自动循环继续暂停 |

主网页卡片的 `completed` 只表示生成和结构处理完成。发布仍保留 `scientific_verified=false`、`scientific_validation_status=unreviewed`、`production_contract_complete=false`。含待核对引文的卡片可以发布为未科学核验的阅读材料。

当前结构与引文检查没有验证核心结论是否由原文科学蕴含，没有完整比较图面数字、公式符号或单位。这解释了为什么高分卡片中能出现10 ps写成100 ps、图轴倍率写错、复共轭符号丢失等问题。相关只读证据见[高分卡片抽查](/Users/xiaoyanhao/project/paper/reports/workflow-audits/高分文献卡片抽查_20261009.md)。

工作台网页卡片分开显示“生成完成”“结构检查”“引文逐字同页匹配 X/Y”“科学复核未进行”。引文统计使用 `evidence_status` 和匹配类型，不再用旧图式流程的 `status` 字段判断网页引文是否匹配。
