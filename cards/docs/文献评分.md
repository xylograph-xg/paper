# GPT文献评分

> 历史说明：本文记录 2026-10-08 的 `paper-evaluation-v1` 方案；现行标准为 `paper-evaluation-v2`，由制卡网页直接给出两项整体分（总体质量、方向新颖性），后台不重算分项总分。v1 的升级事件与旧分数保留，不用于新制卡。现行规则见[文献质量评分标准](文献质量评分标准.md)。

当前主Catalog精选网页制卡增加两个0–100分指标：总体质量（overall_quality）与方向新颖性（direction_novelty）。总体质量看论文方法、证据与对照、结论匹配、限制交代；方向新颖性仅依据原文对前人工作的比较，评估研究问题、机制/材料/方法路线的新意。不因期刊、入选制卡加分，不把作者“首次”当作已验证的全球首次，不联网补领域排名。证据不足输出null与中文理由。

每项含score、reason、source_pages，保存在card.json顶层paper_evaluation；本文记录的 v1 评分输入版本为paper-evaluation-v1，现行新制卡使用 v2。新版本完整结果须包含两项，数值为有限0–100数字，打分须有合法原文页码依据；旧版本结果兼容，不补造分数。工作台卡片顶部显示两项分数，展开显示依据与页码。它们评价论文，不是资料卡独立科学评审分数，不改变科学核验、生产合同和原有验收要求。

生成材料的空白结构和通用提示加入要求，并冻结到packet指纹。2026-10-08在主库共享提交锁和数据库事务保护下，仅为54份queued且原记录证明未发送的缓存输入升级；保留原prompt/context/packet备份，PDF不改。12份尚未准备材料的任务在以后准备时自动使用新版。活动、已提交、不确定和已有卡片不改不重发；详见 `infrastructure/data/paper-evaluation-input-upgrade.json`。

验证：26项评分、输入结构、人工保护、网页收取回归测试通过；隔离无头工作台验证两项评分、依据页码、文本转义和信息不足显示通过。测试不声称已有真实GPT评分；分数随后续实际结果收取保存。
