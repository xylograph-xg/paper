1. **浏览器退出后等待不恢复。** 原启动记录已ready便提前返回。现在原所有者在有效原登记、已完整就绪旧启动、相同profile/端口进程不存在及端点不可达的两次相隔30秒实查后，归档旧请求/登记再生成一次新nonce。每小时最多2次、间隔5分钟；存续进程、部分启动、损坏登记、未知启动及人工验证不另开，写入中断也只续同一意图。不关闭存续浏览器，不修改旧材料账本。
2. **启动检查被缺失输入框串行拖慢。** 直接读取原有有界页面快照的真实composer_available和错误状态。一个未就绪页面保持opening，其他页面继续检查；没有省略模型或发送前核对。
3. **主页重试错误被算作健康。** 增加实机出现的短文案“请重试，或退出登录后重新登录”，仍要求visible_main_notice_ui来源。未知错误、输入框不可用不再计为健康空白页；原归属、完整历史、生成/上传/草稿/登录/额度、两轮稳定和归档/CAS保护继续。
4. **真实PUT协议错误没有及时限制新派发。** 原固定页、原上传意图绑定的HTTP/2、网络变化或连接中断接入已有五分钟网络冷却。只限制新派发，原观察/收取继续；ERR_FAILED/ABORTED、未归因或HTTP拒绝不据此重传。网络错误不能缩短或覆盖尚未结束的额度等待，也不把冷却到期说成网站恢复。
5. **本机盘点受系统代理影响。** 原watcher的本机HTTP元数据明确使用空ProxyHandler，只接受本机显式端口，拒绝认证、路径和查询。网站和材料上传仍使用用户线路；不另连CDP。实际本机读取对照两条路径均取得20页，本轮未把先前502的具体来源冒称已证明。
6. **HTTP拒绝诊断不足。** 在原网络事件中只保留白名单x-ms-error-code和数字Retry-After；认证、Cookie、签名路径/参数和响应正文均不写入。没有由403自动推断额度或授权失效。
